# Landing Page — Leaderator Project 1

A responsive landing page built with **HTML and CSS** as the first project of Bank of Georgia's Leaderator front-end bootcamp (2022).

## What it covers

- Semantic HTML page structure
- Layout with Flexbox
- Responsive design with media queries (`responsive.css`)
- Translating a design mockup into a pixel-accurate page

## Running locally

No build step needed. Clone the repo and open `landingpage.html` in your browser.

```bash
git clone https://github.com/TaTamta/Project-1.git
```
